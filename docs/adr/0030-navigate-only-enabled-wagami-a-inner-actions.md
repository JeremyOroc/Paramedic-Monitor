# Navigate only enabled Wagami A inner-display actions

Wagami A's lower-shell Left/Right buttons cycle through enabled actions in the current inner
display and Enter activates the visibly selected action once. On the live screen this includes
the six right-dock tasks in row order followed by touchscreen energy controls; shell actions,
read-only vital displays, and guarded/disabled options are excluded, while secondary views
have their own cyclic selection and restore the live selection on return. This avoids using
ordinary navigation to trigger protected Shock or an unavailable clinical action while still
giving the immediately visible six destinations physical-key access.
