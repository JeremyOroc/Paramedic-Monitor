# Add Wagami A without retiring Wagami X

Wagami A is a distinct defibrillator model added alongside Wagami X and Wagami Z, not a replacement
for X. Keeping X preserves existing training workflows and saved scenarios, while A can develop an
original device-like visual and interaction design with clinical functions intact. This accepts the
cost of supporting multiple models rather than changing or deleting an established one; Wagami A's
exact interface remains a separate design decision.
